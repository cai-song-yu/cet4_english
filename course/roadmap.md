# 90篇英语训练课程｜整体难度路线图

> 起点：CET-4 约 400 分水平 ｜ 目标：90 天后具备 CET-4 约 520 分的语言能力
> 训练重点：阅读、写作、口语（听力不在此课程内）
> 核心循环：阅读 → 理解 → 词汇积累 → 句型积累 → 写作 → 口语输出

---

## 0. 目标拆解

- **520 分对应的能力**：阅读正确率约 65%+，词汇量约 4500，能读懂中等长度的说明文与议论文，能写结构完整的三段式短文，能用英语连续表达 1–2 分钟观点。
- **起点差距**：约 3000–3500 词，阅读依赖"逐句翻译成中文"，长难句靠猜，写作以简单句为主。
- **90 篇的词汇任务**：每篇净授 8–22 个核心词，全课程净增约 **1100–1400 个核心词**；配合高频复现，累计覆盖四级高频词 **约 2500 个**，足以支撑 520 分的阅读需求。
- **重要原则**：不是背单词课。词汇只在语境中出现、在后续文章中反复复现、最终在写作和口语中被主动调用。

---

## 1. 难度的五个控制维度

难度调整**永远只动其中 1–2 个维度**，绝不同时全部拉高，避免出现"突然变难"的断层。

1. **篇幅**：文章总词数
2. **新词密度**：每 100 词中的生词数
3. **句子复杂度**：平均句长、从句嵌套层数、长难句数量
4. **抽象程度**：具体事实叙述 → 抽象概念、观点与论证
5. **任务难度**：阅读题型 + 写作/口语要求

## 3. 分阶段详述

### 阶段一（第 1–10 篇）｜基础阶段：生活英语
- **水平定位**：高中低年级 / 四级入门，接近 A2–B1。
- **篇幅**：150 → 250 词。
- **词汇**：每篇 8–12 个四级基础高频词（manage, afford, attitude, convenient, suggest 等），新词密度 ≤3%。
- **句法**：简单句为主，每篇 1–2 个 because / when / which 从句；第 1 篇基本不出现长难句。
- **主题**：日常生活、校园、习惯、购物、天气、朋友、作息。
- **阅读训练**：事实细节题、简单指代题、单段段落大意。
- **写作训练**：造句能力——时态一致、there be、连词 and/but/so/because；先写 3–5 句，再过渡到 50–60 词小段。
- **口语训练**：30 秒用自己的话复述文章主要内容。
- **标注强度**：[CET4] 8–12 处、[PHRASE] 3–4、[WRITING] 1–2、[SENTENCE] 0–1、[SYNONYM] 0–1。

### 阶段二（第 11–20 篇）｜基础过渡：日常叙事
- **篇幅**：250 → 320 词。
- **词汇**：10–14 个/篇，密度 3–4.5%；开始出现四级高频抽象词（benefit, influence, opportunity, replace）。
- **句法**：并列句 + 常见从句，每篇 2–3 个值得分析的句子；出现简单非谓语（to do / doing）。
- **主题**：一次经历、社区、兼职、网络使用、家庭与朋友、一次选择。
- **阅读训练**：细节题、简单推断题、段落作用（起承转合）、指代判断。
- **写作训练**：60–80 词，"观点 + 一个理由 / 一个例子"；训练 first / also / however / as a result。
- **口语训练**：45 秒回答问题，必须给出一个理由。

### 阶段三（第 21–30 篇）｜中级：生活与社会话题
- **篇幅**：300 → 400 词。
- **词汇**：12–18 个/篇，密度 4–6%；系统引入四级高频抽象词（environment, resource, opportunity, phenomenon, consumer, reputation）。
- **句法**：定语从句、名词性从句、被动语态、非谓语作状语；每篇 2–3 个 [SENTENCE]。
- **主题**：健康、消费、社交方式、时间管理、城乡差异、环保习惯。
- **阅读训练**：**同义替换识别**（四级阅读核心考点）、主旨题、简单推断、词义猜测。
- **写作训练**：80–100 词，"观点—理由—例子"三要素完整；[WRITING] 标注开始密集。
- **口语训练**：1 分钟陈述观点 + 理由 + 例子。
- **标注强度**：[SYNONYM] 开始系统出现（如 important → significant → essential）。

### 阶段四（第 31–45 篇）｜中级提高
- **篇幅**：400 → 500 词。
- **词汇**：15–20 个/篇，密度 5–7%，抽象名词增多。
- **句法**：长难句 3–5 个/篇——多从句嵌套、插入语、同位语、强调与倒装初步。
- **主题**：科普知识、心理与行为、教育方式、环境问题、城市生活、历史故事。
- **阅读训练**：作者态度题、推断题、论证关系（因果 / 转折 / 举例的作用）、词义猜测、写作目的题。
- **写作训练**：100–120 词，训练对比、因果、转折；段落主题句意识；衔接词 however / therefore / never- less / for instance / on the other hand。
- **口语训练**：1 分钟结构化表达（观点 → 原因 → 例子）。

### 阶段五（第 46–60 篇）｜中高级
- **篇幅**：450 → 550 词。
- **词汇**：15–22 个/篇，密度 6–8%，但复现词比例提高（约 40% 是旧词在新语境中重现）。
- **句法**：自然的复杂句——分词结构、with 复合结构、虚拟语气、名词化表达；开始接触让步状语从句。
- **主题**：经济与消费、AI 与科技、社会议题、商业案例、文化差异、工作与职业。
- **阅读训练**：作者观点与隐含意义、论证结构分析、段落间逻辑、"作者为什么提到 X"题。
- **写作训练**：120–150 词完整四级三段式作文——开头 / 主题句 / 例证 / 让步 / 结尾；词汇升级替换（avoid good/important/bad）。
- **口语训练**：1.5–2 分钟，观点陈述 + 简单反驳对方。

### 阶段六（第 61–75 篇）｜CET-4 强化
- **篇幅**：500 → 600 词，**限时阅读**（先计时做题，再精读）。
- **词汇**：18–25 个/篇，密度 6–8%，以四级高频词的**复现与辨析**为主；重点训练同义替换与干扰项识别。
- **句法**：四级阅读风格长难句 4–6 个/篇。
- **主题**：覆盖四级真题常见题材——教育、科技、社会、健康、文化、工作、环境。
- **阅读训练**：每篇限时 8–10 分钟；题型全覆盖（主旨 / 细节 / 推断 / 词义 / 态度）。
- **写作训练**：120–150 词，**限时 25 分钟成文**；强调句式多样性（强调句、倒装、虚拟、非谓语）与高分表达。
- **口语训练**：2 分钟，要求使用衔接词与本阶段积累的高级表达。

### 阶段七（第 76–90 篇）｜综合提高
- **篇幅**：550 → 700 词。
- **词汇**：密度反而略降到 5–7%——生词不减，但**要求通过上下文猜测**，不再逐词标注所有可能障碍。
- **句法**：接近普通成人的正常英文（杂志文章、评论、随笔），出现轻微反讽、隐含意义、复杂论证。
- **主题**：历史、全球化、伦理、心理、未来工作、教育公平、个人成长等需要理解立场的文章。
- **阅读训练**：隐含意义、作者立场、篇章结构分析、批判性问题（评价论证与假设）。
- **写作训练**：150–180 词，迁移到四级以外的一般英语写作；观点 → 反驳 → 让步 → 总结。
- **口语训练**：2 分钟，观点 + 理由 + 例子 + 让步。
- **第 90 篇**：综合毕业测试（阅读 + 写作 + 口语全流程）。

## 4. 题型与任务的进阶线

**阅读题型**
| 篇目 | 新增题型 |
|---|---|
| 1–10 | 事实细节、单段大意、简单指代 |
| 11–20 | + 简单推断、段落作用 |
| 21–30 | + 主旨题、同义替换识别、词义猜测 |
| 31–45 | + 态度题、论证关系、写作目的 |
| 46–60 | + 隐含意义、作者立场、篇章结构 |
| 61–75 | 全题型限时训练 |
| 76–90 | + 批判性问题（评价论证、假设与证据） |

**写作**
| 篇目 | 要求 |
|---|---|
| 1–10 | 造句（时态 / 连接词） |
| 11–20 | 段落雏形：观点 + 1 个理由 |
| 21–30 | 三要素：观点—理由—例子 |
| 31–45 | 对比 / 因果 / 转折衔接，主题句 |
| 46–60 | 完整三段式，让步，词汇升级 |
| 61–75 | 限时成文，句式多样，高分表达 |
| 76–90 | 反驳与让步，篇章连贯，一般写作迁移 |

**口语**
复述（30秒）→ 回答+理由（45秒）→ 观点陈述（1分钟）→ 结构化表达（1分钟三段）→ 加反驳（1.5–2分钟）→ 加让步的自由表达（2分钟+）

## 5. 知识复现机制（本课程最重要的机制）

1. **新词寿命**：每个新授核心词必须在**之后 5 篇内至少复现 3 次**，全课程累计复现 6–10 次，且尽量出现在不同语境。
2. **写文章时优先用旧词**：生成新文章时，优先把前面已学的词汇、短语、句型编织进新语境，再加入少量新词。
3. **复现层次递进**：见到认识 → 读懂语境 → 辨析差异 → 在写作/口语中主动使用。后两个层次靠写作和口语任务强制调用。
4. **每篇标注复现词**：每篇「本篇学习重点」中列出 3–5 个"本篇复现的旧词/旧句型"。
5. **节点复盘**：每 10 篇（节点篇）抽查旧词掌握情况，把薄弱词写入后续文章的复现队列。

## 6. 动态难度调整规则

每篇结束后我都会请你给一个反馈（自评 1–5 或直接说"太简单/刚好/太难"）。

| 你的反馈 | 我的调整 |
|---|---|
| 太简单 | 下一篇**只调 1–2 个维度**：新词密度 +1%，或篇幅 +10%，或长难句 +1；其余保持不变 |
| 连续 2 篇太简单 | 整体进度提前约 2–3 篇进入下一阶段 |
| 太难 | 下一篇：新词密度 −1~1.5%，篇幅 −15%，长难句 −2，抽象概念改具体，多放旧词；**同难度维持 2 篇再考虑上升** |
| 阅读题正确率 <60% | 降一档，并插入 1 篇"复现篇"（以旧词旧句型为主） |
| 阅读题正确率 >85% 且写作顺畅 | 升一档 |
| 某类任务特别吃力（如长难句 / 写作 / 口语） | 后续 3–5 篇针对该薄弱点加密训练，不整体升降 |
| 无反馈 | 按本路线图默认进度推进 |

**总原则**：90 篇只是路线，不是刻度。难度以你的真实表现为唯一依据，阶段边界允许前后浮动约 ±5 篇。

## 7. 90 天节奏与每日流程

- **节奏**：每天 1 篇，90 天 90 篇；复习融入每天流程，不占用新篇目。
- **每日流程（约 45–60 分钟）**：
  1. 通读文章，不查词，先猜（8–10 分钟）
  2. 完成阅读理解题（5 分钟）
  3. 对照标注与知识总结精读（15 分钟）
  4. 完成写作任务（15–20 分钟）
  5. 完成口语任务（2–3 分钟）
  6. 反馈：难度自评 1–5 + 卡住的地方
- **每周末**：10 分钟周复盘——回顾本周 7 篇的词汇表，把仍然模糊的词告诉我，我加入复现队列。

## 8. 每篇输出格式（已确认）

> 📌 标注细则见 `course/style-guide.md`（v3.1 规范：**前端交付** + 颜色标注 + 音标 + 搭配含中文意思）
> 📖 交付方式：文章数据追加到 `assets/js/articles.js`，前端 `index.html` 自动渲染，**不为单篇文章写任何页面代码**。

**第X篇｜标题**
1. 颜色图例
2. 英文正文（**纯英文、不混中文**；**颜色标注 + 加粗**，不加音标；所有解释放正文下方的表格）
   - 🔵 蓝色 = CET-4 核心词（加粗）
   - 🟢 绿色 = 高频短语/固定搭配（附中文意思）
   - 🟠 橙色 = 写作表达
   - 🔴 红色 = 长难句
   - 🟣 紫色 = 同义替换/辨析
3. 核心词汇表（**Word 与音标同一格**：`**afford** /əˈfɔːd/`，不单独设音标列；含中文 / 常见搭配含意思 / 例句）
4. 高频短语与固定搭配（每个搭配**必须给中文意思**，重点收动词搭配；**不标音标**）
5. 写作表达（中文 / 含义 / 语境 / 替换 / 正式程度）
6. 重点句子解析（2–5 句）
7. 阅读理解训练（3–5 题，不给答案；题目含 `ans`/`ansCn`，前端以「显示参考答案」按钮默认隐藏）
8. 输出任务（写作迁移 + 口语任务，并排展示）
9. 本篇学习重点（含本篇复现的旧词）
