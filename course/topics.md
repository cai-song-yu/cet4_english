## 生成注意事项

1. **叙事文的口吻**：阶段二以第一人称叙事为主；阶段三夹叙夹议；阶段四起转为说明文 / 议论文（可保留少量例子），阶段五以后以"观点 + 证据 + 让步"的议论为主。
2. **人物连续性**：允许并鼓励让同一位"室友 / 王老师 / 邻居陈阿姨"等在不同篇目里再次出现，营造课程连载感（但每篇必须独立可读）。
3. **节点篇（20 / 30 / 45 / 60 / 75 / 90）**：`focus` 必须 7 条，含 ⭐ 本阶段复盘（词汇抽查 / 已掌握句型 / 下阶段难度确认）。
4. **每篇必做**：`w-rev` 灰点复现此前文章教过的词（阶段二 4–8 处，逐阶段增加），并在 `focus` 里点名复现了哪些旧词。
